# Sayed Mohammed — Portfolio

Professional AI Engineer portfolio built with React and Vite.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run lint
npm run build
npm run preview
```

The portfolio content is kept in `src/data/portfolio.js`. The design uses a slate color system, Manrope typography, IBM Plex Mono metadata, light/dark themes, and scroll-triggered reveals.
